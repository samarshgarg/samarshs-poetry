# /images

Drop your generated images here using the filenames listed in **../IMAGE-BRIEF.md**
(e.g. `cover-heart.jpg`, `poem-for-u.jpg`).

Until you do, the site shows an elegant placeholder card in each image slot that
displays the exact AI prompt and required dimensions — so nothing looks broken.

## Wiring an image in once you've made it

The placeholders are generated by one function in `js/app.js` called
`imgPlaceholder(...)`. To swap a real image in, you can either:

1. **Quick way** — replace the `<figure class="img-ph">…</figure>` output for that
   slot with `<img src="images/poem-<slug>.jpg" alt="…" class="poem-img">`, or
2. **Tell your developer / ask Claude again** — say *"wire the real images from
   /images into the site"* and the placeholder logic will be upgraded to show the
   real file when it exists and fall back to the placeholder when it doesn't.

Recommended export: **JPG or WebP, ~80% quality**, sized to the dimensions in the brief.
